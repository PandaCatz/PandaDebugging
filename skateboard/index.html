Every board in the game is assembled from swappable parts — 3 decks, 3 trucks, 3 wheels, plus 5 bottom graphics and 6 grip designs that swap as textures. Every dimension traces to a published spec or a measured product photo; every graphic is original, so it all ships clean. This page is the working reference: what exists, how parts attach, and how to regenerate or extend the kit.

How parts attach the modular contract

deck
 ├─ Socket_TruckFront      mount-plane centre of the front 4-hole group
 ├─ Socket_TruckRear       same, yawed 180° (kingpins face each other)
 └─ SM_Grip_*              separate mesh + material slot (alpha-capable)
truck
 ├─ Socket_WheelL/R        wheel seat centres; spin axis = socket local Z
 └─ *-convcolonly          convex hull → Godot auto-collision (invisible)

Anything placed at a socket with an identity local transform is correctly mounted. Deck shapes move the trucks; truck widths move the wheels — no per-combination tuning, ever. Units are metres at real scale. Part metadata (axle width, wheel diameter, deck thickness) rides along as GLTF extras → node.get_meta("sk8_axle_mm").

Using it in Godot godot/ runs today

var board := SkateboardAssembly.new()
add_child(board)
board.build({
    "deck": "street_80",        # street_80 | street_825 | shaped_887
    "truck": "139",             # 139 | 144 | 159
    "wheel": "street_54",       # street_54 | park_54c | cruiser_60
    "graphic": "soaked",        # 5 sets
    "grip": "print_mountain",   # 6 sets
})
board.rebuild({"graphic": "gigflyer"})   # swap anything, any time

Demo controls: Q/A deck · W/S trucks · E/D wheels · R/F graphic · T/G grip · Y/H finish · U/J urethane · Space random. The -convcolonly hulls become collision on import — physics comes free with every part.

Regenerating & extending pipeline is law

python  tools/generate_textures.py        # 17 texture sets first
blender -b -P tools/build_skateboard.py -- --bake     # bake exactly once
blender -b -P tools/render_catalog.py     # beauty shots (GPU)
Order matters — bake multiplies AO into the metal/rough maps. Running bake twice double-darkens; regenerating textures without re-baking erases AO. Textures → build+bake → renders.
  • New graphic: one function in sk8_designs.py + one registry entry. No mesh work.
  • New deck shape: published W/L/WB/nose/tail + a straight-on product photo through extract_outline.py.
  • New truck/wheel: one dict entry from the maker's spec table — the castings are parametric.
  • Quality gate: tools/v2_audit.py must stay all-green (budgets, n-gons, naming, colliders); Godot must import clean headless.
